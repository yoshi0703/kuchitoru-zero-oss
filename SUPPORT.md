# Support / サポート

## Community edition

不具合報告と再現可能な機能要望はGitHub Issues、使い方の相談はGitHub Discussionsを利用してください。Issueにはバージョン、導入方式、再現手順、期待結果、実際の結果を記載し、秘密情報や顧客データを含めないでください。

Use GitHub Issues for reproducible bugs and focused feature requests, and GitHub Discussions for usage questions. Include the version, installation method, reproduction steps, expected result, and actual result. Never include secrets or customer data.

自己ホスト環境のインフラ運用、外部API契約、個別の設定代行、データ復旧、常時監視に対するSLAはありません。導入者が更新、バックアップ、監視、法令・各プラットフォーム規約への適合を管理します。

There is no SLA for self-hosted infrastructure, third-party API contracts, configuration services, data recovery, or continuous monitoring. Operators are responsible for updates, backups, monitoring, and compliance with applicable law and platform policies.

セキュリティ問題はIssueではなく [SECURITY.md](SECURITY.md) の方法で報告してください。

Report security issues through [SECURITY.md](SECURITY.md), not a public issue.

## Hosted edition

Hosted版の契約、請求、アカウントに関する問い合わせはCommunityのIssueでは扱いません。[クチトルZero](https://app.kuchitoru.com/contact) の問い合わせ窓口を利用してください。

Hosted billing, contracts, and account support are not handled in Community issues. Use the contact channel at [Kuchitoru Zero](https://app.kuchitoru.com/contact).
